# Tangkapan layar tutorial sekolah

Gambar untuk *Tutorial ARKAS Web Langkah demi Langkah* (Operator, Kepala Sekolah, Bendahara, Komite).
Setiap gambar diberi kotak merah pada tombol/kolom yang perlu diklik, diambil dari aplikasi yang berjalan
dengan Playwright (1280 px × 1,25), lalu dikompres ke palet 256 warna.

Awalan berkas: `o` Operator, `k` Kepala Sekolah, `b` Bendahara, `m` Komite; angka mengikuti urutan langkah.

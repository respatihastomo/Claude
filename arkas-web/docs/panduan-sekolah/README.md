# Tangkapan layar panduan pengguna sekolah

Gambar untuk *Panduan Penggunaan ARKAS Web untuk Sekolah* (Operator, Kepala Sekolah, Bendahara).
Diambil dari aplikasi yang berjalan (6 proses, data demo) dengan Playwright, 1280 px × 1,5, lalu dikompres ke palet 256 warna.

Urutan berkas mengikuti alur kerja: masuk (01–02), RKAS (03–09), transaksi & pajak (10–19), penutupan buku (20–21), laporan (22–23), kelola pengguna (24).

Untuk mengambil ulang: siapkan basis data baru, jalankan semua layanan, lalu `DEMO_TANPA_TUTUP=1 node scripts/isi-demo.mjs` bila penutupan buku ingin diperagakan lewat UI.
